# ML Gym

Project-based learning of machine learning algorithms using real-world datasets.

## About

This repository is a hands-on space for practising machine learning concepts by building small projects from start to finish. Each project focuses on understanding the data, preparing useful features, training models, evaluating results, and learning from the process.

The repository is intended for learning and experimentation. The notebooks and models are not presented as production-ready solutions.

## Learning Goals

The projects will cover machine learning topics including:

- Data cleaning and exploratory data analysis
- Feature engineering and preprocessing
- Linear regression
- Logistic regression
- Classification algorithms
- Decision trees and random forests
- Clustering
- Model evaluation and comparison
- Cross-validation and hyperparameter tuning
- Practical machine learning workflows

More algorithms and projects will be added over time.

The datasets used in this repository are collected from [Kaggle](https://www.kaggle.com/). Please refer to the relevant Kaggle dataset page for the original source, license, and usage conditions.

## Getting Started

1. Clone the repository.
2. Set up the Python environment described in `pyproject.toml`.
3. Open a project notebook from the relevant `notebooks` directory.
4. Run the notebook cells in order and experiment with the workflow.
